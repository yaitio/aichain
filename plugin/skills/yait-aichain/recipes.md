### Define a custom tool that converts Celsius to Fahrenheit, call it directly with 100, and print the result.

```python
from yait_aichain.tools import Tool

    name = "c_to_f"
    description = "Convert Celsius to Fahrenheit."
```

### Define a custom tool that returns the first N words of a text, where N is an optional setting defaulting to 3. Call it with N=2 on 'alpha beta gamma delta' and print the result.

```python
from yait_aichain.tools import Tool
class FirstWords(Tool):
    name = "first_words"
    description = "Return the first N words."
    parameters = {"type": "object", "properties": {
        "input": {"type": "string"},
        "options": {"type": "object", "properties": {"n": {"type": "integer"}}}},
        "required": ["input"]}
    def run(self, input, options=None):
        return " ".join(input.split()[: (options or {}).get("n", 3)])
```


### Build a pipeline that drafts a reply with an LLM, pauses until a human approves the draft, then finishes with a tool that 'sends' the approved text. The pause must be resumable from another process. Simulate the approval in the same script, resume, and print what was sent.

```python
from yait_aichain import Chain, Model, Skill
from yait_aichain.state import FileStore, SuspendedResult
from yait_aichain.tools import Tool, Wait
class Send(Tool):
    name = "send"
    description = "Send the reply."
    parameters = {"type": "object", "properties": {"reply": {"type": "string"}}, "required": ["reply"]}
    def run(self, reply, options=None):
        return f"sent: {reply}"
draft = Skill(Model("gpt-5.4-mini"), prompt="Draft a polite reply to: {complaint}")
chain = Chain(steps=[(draft, "reply"), (Wait(reason="approve?", resume_with={"reply": "str"}), "approval"),
                     (Send(), "sent")], store=FileStore("runs"))
result = chain.run(variables={"complaint": "late delivery"})
assert isinstance(result, SuspendedResult)
print(chain.resume(result.run_id, signal={"reply": result.document["variables"]["reply"]}))
```

### Build an agent with a tool that stores a final answer into a Python dict. The run may count as successful only when that answer has been stored — verified by your code, not by the model saying it is done. Print how the run stopped.

```python
from yait_aichain import Agent, Model
from yait_aichain.agent import check, step_count
from yait_aichain.tools import Tool
store = {}
class Save(Tool):
    name = "save_answer"
    description = "Store the final answer."
    parameters = {"type": "object", "properties": {"input": {"type": "string"}}, "required": ["input"]}
    def run(self, input, options=None):
        store["answer"] = input
        return "stored"
agent = Agent(Model("gpt-5.4-mini"), tools=[Save()],
              stop_when=[check(lambda state: "answer" in store, name="stored",
                               output=lambda state: store["answer"]), step_count(10)])
result = agent.run("What is the tallest mountain? Store the answer.")
print(result.output, result.stopped_by)
```

### Build an agent with a refund tool marked as a financial-risk action. Refunds must be approved by a function that allows amounts up to 50 and refuses larger ones with a reason. Ask the agent to refund 80 for order 42. Print the result.

```python
from yait_aichain import Agent, Model
from yait_aichain.tools import ApprovalDecision, Tool
class Refund(Tool):
    name = "issue_refund"
    description = "Refund an order."
    risk = "financial"
    parameters = {"type": "object", "properties": {"amount": {"type": "number"}}, "required": ["amount"]}
    def run(self, amount, options=None):
        return f"refunded {amount}"
def approve(request):
    return True if request.arguments.get("amount", 0) <= 50 else ApprovalDecision(False, "over 50")
agent = Agent(Model("gpt-5.4-mini"), tools=[Refund()],
              policy={"rules": {"financial": "approve"}, "approve": approve})
print(agent.run("Refund 80 for order 42.").output)
```

### Drive an agent's loop yourself, step by step, instead of calling run(): execute every tool call it asks for and feed each result back until it gives an answer. Use one tool you define. Print the final answer.

```python
from yait_aichain import Agent, Model
from yait_aichain.models import ToolCallRequest, tool_result_turn
from yait_aichain.tools import Tool
class Echo(Tool):
    name = "echo"
    description = "Echo text."
    parameters = {"type": "object", "properties": {"input": {"type": "string"}}, "required": ["input"]}
    def run(self, input, options=None):
        return input
agent = Agent(Model("gpt-5.4-mini"), tools=[Echo()])
state, messages = agent.new_state(), agent.opening("Echo 'hi' then answer.")
while True:
    reply = agent.step(messages, state)
    if not isinstance(reply, ToolCallRequest):
        print(reply)
        break
    messages.append(reply.as_turn())
    for call in reply.calls:
        result, error = agent.execute(call, state)
        messages.append(tool_result_turn(call.id, error or result))
```
